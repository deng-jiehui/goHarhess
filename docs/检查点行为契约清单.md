# 检查点与恢复行为契约清单

阶段四 Gate 产物。条款从 `checkpoint_resume`、`exec_tree`、`mode_parity`、
`interrupt_input`、`checkpoint_parallel`、`dispatch`、`abandon`、
`pkg/state` 测试与 5.5 的两条并发保护中提取，是检查点简化、并行统一与
子 Agent 重建必须满足的行为基线。每条注明契约来源测试；简化后语义
改变的条款单列在「变更点」一节，不混入保留契约。

## K. 变更点（本阶段语义改变，非保留项）

以下旧契约被本阶段有意废弃，测试同步删除或改写：

1. **条目化契约 → 整图指纹。** 图结构任何变化即拒绝恢复；不再允许
   「恢复闭包之外」的增删。`TestResumeAllowsChangesOutsideResumeClosure`
   删除；`TestResumeRejectsChangesInsideResumeClosure`、
   `TestResumeRejectsDeletedDownstreamPath`、
   `TestResumeWithoutContractStillRequiresExactRevision`、
   `TestExecTreeRejectsChangedChildRevision` 改写为整图指纹拒绝场景；
   `TestDispatchResumeRejectsJoinChange`/`MemberPathChange` 由指纹比对覆盖。
2. **删除 `WithMigration` 与 codec 迁移。** codec 版本不一致即拒绝；
   `TestResumeMigration*`、`TestNestedChildMigrationKeepsOwnCodecBoundary`
   删除。State codec 自身的 `WithMigration` 声明随之移除。
3. **exec tree → namespace 前缀。** 嵌套执行树不再随检查点持久化；
   开发期旧检查点不保证恢复（审查报告已声明）。`TestExecTreeLegacyFlatCheckpointStillResumes`、
   `TestInputCheckpointCopiesRecordsAndRejectsLegacyFormat` 的旧格式断言、
   `TestDecodeCheckpointRejectsLegacyFormats`、`TestRejectOldCheckpointFormat`
   中依赖旧树格式的部分相应调整。
   **落地形态（独立记录、键带前缀）**：子执行进度保存在独立检查点记录，
   键 = 属主 frame 前缀 + `/` + childKey（根前缀为 `记录键/RunID`，
   新一轮运行换 RunID 使旧代子记录全部失效）；`childExecution` 只登记
   身份、记录键与挂起时上报的待答问题副本，父级 pending 聚合与重驱
   判定以该副本为准；恢复输入经 ctx 透传各层按待答 ID 匹配消费。
   受管任务 frame 仍内嵌其属主记录，随 extensions/subagent 重建迁移。
4. **`AddParallelNode` 删除。** `parallel.go` 及其展开逻辑移除；
   `parallel_review_test.go`、`parallel_expand_test.go`、
   `runtime_parallel_test.go` 中仍可保留的行为迁移到 Fork/Join + `Send`
   等价用例（组级合并器、成员路由、成员局部态、恢复语义均已由
   Fork/Join 侧测试覆盖）。
5. **子 Agent 出核心。** `managed_tasks.go`、`session_agents.go`、
   `pkg/subagent` 及其测试随重建迁移；`TestCheckpointSubAgentsIsolatedValidatedAndCarried`
   等存储层子 Agent 记录测试按新实现形态调整。
