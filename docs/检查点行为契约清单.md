阶段四 Gate 产物。条款从 `checkpoint_resume`、`exec_tree`、`mode_parity`、

## J. 子 Agent 重建契约（extensions/subagent，选项 B 精简版）

决策见方案第十节决策四。子 Agent 改为“在工具调用里同步运行的子图”：工具调用内
发起的嵌套运行按调用身份成为子执行，写入独立命名空间记录（`exec_tree.go` 中
`callSite` 的序号规则），因此 E 节的嵌套挂起、结果复用、兄弟完成态保留直接适用。
后台异步任务模型整体放弃，相关条款列入 K 节第 6 项。

硬性约束：扩展只使用 `graph`、`agent`、`state`、`tool` 的公开 API。实现中一旦需要
访问引擎内部（协调器、并发槽、检查点记录的私有字段），先停下重新评估，不为扩展
给引擎新增公开扩展点。

## K. 变更点（本阶段语义改变，非保留项）

以下旧契约被本阶段有意废弃，测试同步删除或改写：

1. **条目化契约 → 整图指纹。** 图结构任何变化即拒绝恢复；不再允许
   「恢复闭包之外」的增删。`TestResumeAllowsChangesOutsideResumeClosure`
   删除；`TestResumeRejectsChangesInsideResumeClosure`、
   `TestResumeRejectsDeletedDownstreamPath`、
   `TestResumeWithoutContractStillRequiresExactRevision`、
   `TestExecTreeRejectsChangedChildRevision` 改写为整图指纹拒绝场景；
   `TestDispatchResumeRejectsJoinChange`/`MemberPathChange` 由指纹比对覆盖。
2. **删除 `WithMigration` 与 codec 迁移。** codec 版本不一致即拒绝；
   `TestResumeMigration*`、`TestNestedChildMigrationKeepsOwnCodecBoundary`
   删除。State codec 自身的 `WithMigration` 声明随之移除。
3. **exec tree → namespace 前缀。** 嵌套执行树不再随检查点持久化；
   开发期旧检查点不保证恢复（审查报告已声明）。`TestExecTreeLegacyFlatCheckpointStillResumes`、
   `TestInputCheckpointCopiesRecordsAndRejectsLegacyFormat` 的旧格式断言、
   `TestDecodeCheckpointRejectsLegacyFormats`、`TestRejectOldCheckpointFormat`
   中依赖旧树格式的部分相应调整。
   **落地形态（独立记录、键带前缀）**：子执行进度保存在独立检查点记录，
   键 = 属主 frame 前缀 + `/` + childKey（根前缀为 `记录键/RunID`，
   新一轮运行换 RunID 使旧代子记录全部失效）；`childExecution` 只登记
   身份、记录键与挂起时上报的待答问题副本，父级 pending 聚合与重驱
   判定以该副本为准；恢复输入经 ctx 透传各层按待答 ID 匹配消费。
   （已落地：受管任务 frame 随第 5、6 项一并删除。）
4. **`AddParallelNode` 删除。** `parallel.go` 及其展开逻辑移除；
   `parallel_review_test.go`、`parallel_expand_test.go`、
   `runtime_parallel_test.go` 中仍可保留的行为迁移到 Fork/Join + `Send`
   等价用例（组级合并器、成员路由、成员局部态、恢复语义均已由
   Fork/Join 侧测试覆盖）。
5. **子 Agent 出核心。** `managed_tasks.go`、`session_agents.go`、
   `pkg/subagent` 及其测试随重建迁移；`TestCheckpointSubAgentsIsolatedValidatedAndCarried`
   等存储层子 Agent 记录测试按新实现形态调整。删除顺序见方案阶段四：先让
   `extensions/subagent` 通过 J 节测试，再用单独提交删除核心代码。
6. **放弃后台异步子任务模型。** 子 Agent 只在工具调用内同步运行，以下旧契约
   不再保留，对应测试随核心代码删除：
   - 收件箱、运行中补充消息与 ack 重放去重：`TestManagedMessageInbox`、
     `TestManagedInboxAckReplayAcrossSuspend`。
   - 取消运行中的任务及级联取消：`TestManagedCancelCascade`、
     `TestManagedSuspendedTaskInterrupts`。
   - 任务存活不依赖创建它的节点、跨节点等待作用域：`TestManagedSurvivesParentNode`、
     `TestManagedWaitScope`。
   - 根运行完成前等待后台任务收敛：`TestManagedRootCompletionAfterConverge`。
   - 子任务与图批任务共享同一并发额度：`TestManagedSharedConcurrencyQuota`、
     `TestReviewManagedParallelSubgraphQuota`（改为扩展内独立上限，见 J2）。
   - 跨层级唯一的任务 ID：`TestManagedIDHierarchyUnique`（子执行身份由调用身份
     决定，不再单独分配任务 ID）。
   - 对应的模型工具 `send_message`、`cancel_agent`、独立的 `wait_agents` 一并移除；
     `examples/subagent` 按新形态改写，冒烟测试的期望输出同步调整。
7. **父运行 abandon 不再回滚会话子 Agent 记录。** 子 Agent 会话改为独立
   记录后，`state.AbandonRun`（含 `WithAbandonUnfinished` 内部路径）执行
   期间扩展没有介入点，同步回滚不可能；abandon 本就只回滚会话与执行
   数据、不回滚副作用，子 Agent 会话记录属其自身数据。子 Agent 元数据
   记录创建者 RunID，扩展提供显式 `Cleanup` 入口按 abandoned 运行的
   RunID 清理孤儿记录。`TestSessionAgentsRolledBackByAbandon` 随核心代码
   删除，扩展侧为 `Cleanup` 新增测试。
