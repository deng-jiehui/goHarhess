# 统一检查点对象

对外只保留 `state.Checkpoint`，Graph 的执行进度作为其中的 `Execution` 数据保存。内部保留执行进度结构和调度校验，不再有独立版本、创建时间或公开的导入导出接口。

实施顺序：
1. 增加中断返回持久化检查点、完整检查点导出导入、内部进度无独立版本的契约测试。
2. 将 Continuation 收为 Graph 私有执行进度，统一检查点格式版本和错误分类。
3. 调整中断、恢复、检查点写入和测试，验证中断返回的 ID 与实际存储一致。
4. 更新 1.5、1.6 和使用文档，回归核心、extensions 与竞态测试。

State Codec 继续单独版本化，因为它描述业务状态的编码，不是另一个检查点。旧格式明确拒绝，不保留公开 Continuation 兼容别名。
