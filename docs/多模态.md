# 多模态指南

当前支持范围：**只有图片输入**，且仅限内置 OpenAI 兼容适配器。
文件、音频、视频块会在编码时明确报错，不会静默降级。

## 图片输入

```go
// URI 形式（http/https 地址直发）
schema.NewImageBlock("https://example.com/image.png", "image/png")

// 本地文件：先经 media.Resolver 解析为 data URI 或内联 Data
schema.ContentBlock{ /* media 解析后的内联块 */ }
```

- `image` 块的 `URI` 仅接受 http(s)；`file://` 等本地 URI 需先经
  `media.Resolver` 换内联，或自己转成 `data:` URI / `Data` 字段。
- 发送图片要求模型 `Capabilities.Vision` 显式开启（默认关闭）；
  不支持视觉的模型收到图片块会明确报错而不是偷偷丢弃。
- 混合 content（文本+图片）按原顺序编码为 content 数组。

## 媒体解析与保护（`extensions/media`）

```go
resolver, _ := media.NewResolver(media.ResolverConfig{
    AllowedSchemes:       []string{"https", "file"},
    AllowedHosts:         []string{"cdn.example.com"},
    FileRoots:            []string{"/var/app/uploads"},
    MaxBytes:             4 << 20,
    AllowedMIME:          []string{"image/png", "image/jpeg"},
    BlockPrivateNetworks: true, // 与 MCP 共用 netguard 私网拦截
})
model = resolver.WrapModel(model) // 模型调用边界解析 URI → 内联副本
```

关键语义：**解析结果只进本次请求的消息副本**——调用方消息与检查点
里保存的始终是 URI 引用，不存媒体字节。策略默认全不放行。

`media.NewStoreGuard(store, maxInlineBytes)` 是检查点守卫装饰器：
内联媒体超限的保存直接 `ErrMediaTooLarge`。

## 检查点与成本注意

- **引用而不是内联**：媒体以 URI 引用进消息历史，检查点体积小、
  保存快；内联会显著放大每条消息的字节与 token 成本。
- **媒体不进事件与日志**：观测事件带的是元数据（size/MIME/来源），
  不带字节本体；敏感媒体靠 `observe` 的元数据脱敏键控制。
- **成本**：图片按模型计费规则计 token；重复调用同一 URI 每次都
  重新取回——热点媒体在应用侧加缓存。
